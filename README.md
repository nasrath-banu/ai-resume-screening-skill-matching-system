# AI-Based Resume Screening and Skill Matching System

## Overview
This project is an NLP-based resume screening system that analyzes resumes
and matches them with job roles using machine learning techniques.

## Features
- Resume parsing (PDF/DOCX)
- TF-IDF based feature extraction
- Role-based skill matching
- Resume scoring
- Streamlit web interface

## Tech Stack
- Python
- NLP
- TF-IDF
- Scikit-learn
- Streamlit

## How It Works
1. Upload resume (PDF/DOCX)
2. Extract text and preprocess
3. Apply TF-IDF vectorization
4. Match skills with job role
5. Generate resume score

## How to Run
pip install -r requirements.txt
streamlit run app.py
